# Oferta Hefesto
Implementación y mantenimiento de automatizaciones: cobrar diagnóstico, flujo inicial, conexión por sistema y mensualidad por operación/soporte/monitorización. Delimitar volumen, horario de atención y sistemas autorizados antes de cotizar.

Node-RED es adecuado para flujos técnicos, HTTP, eventos y dispositivos. No sustituye ERP ni plataforma de cobro. Este paquete no incluye conectores comerciales, dashboard propio, IA o infraestructura de alta disponibilidad. Conservar interfaz/avisos de Node-RED y licencia Apache2.0 incluida.

Una instancia por cliente facilita permisos y traspaso. Para pruebas mostrar demo GET protegido, edición del flujo y resultado manual; luego implementar un caso real autorizado con ensayo de recuperación.
